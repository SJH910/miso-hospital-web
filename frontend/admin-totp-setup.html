로그인 보안 설정

새 위치 로그인 추가 인증 (TOTP)

등록해두면, 관리자 계정으로 처음 보는 IP·지역에서 로그인할 때 비밀번호 외에 구글 OTP·Authy 같은 인증 앱의 6자리 코드도 함께 입력해야 로그인이 완료됩니다. 등록하지 않아도 로그인은 계속 가능하지만, 이 추가 보호는 적용되지 않습니다.

  1. 아래 "등록 시작" 버튼을 눌러 비밀키를 발급받습니다.
  2. 구글 OTP(Google Authenticator), Authy 등 인증 앱에서 "QR 코드 스캔"으로 아래 QR을 찍거나, "수동으로 키 입력"을 선택해 비밀키를 직접 입력합니다.
  3. 앱에 표시되는 6자리 코드를 아래 입력창에 넣고 "등록 완료"를 누릅니다.

# 병합 작업 구현 계획서 (hospital_agent.py)

팀원분이 작성하신 휴진일 및 자연어 날짜 파싱 로직(공용 업로드 버전)과 현재 제 맥(Mac)에 적용되어 있는 `audit_decorator` 기능이 충돌하지 않도록 두 코드를 병합(Merge)하는 계획입니다. 사용자님의 지침에 따라 코드의 핵심 로직은 건드리지 않고 누락된 기능만 안전하게 합칩니다.

## ⚠️ User Review Required

본 계획서는 파일 덮어쓰기로 인해 서로의 코드가 유실되는 것을 방지하기 위해 작성되었습니다. 
아래 병합 방식을 확인하시고 승인(Proceed)해 주시면 실제 코드 반영을 진행하겠습니다.

## 💡 병합 전략 (Proposed Changes)

현재 제공해주신 팀원분의 코드(휴진일 처리 및 고급 자연어 파싱)를 베이스로 삼고, 오늘 저희가 작업했던 **"감사 로그 데코레이터(`@audit_log`)"** 설정만 덧붙이는 방식으로 병합합니다.

### `chatbot-service/hospital_agent.py`

#### 1. Import 문 병합
팀원분의 코드 상단에 저희가 추가했던 `audit_decorator` 모듈 임포트를 추가합니다.
```diff
  import tools_db
+ from audit_decorator import audit_log
```

#### 2. 각 Tool 함수에 `@audit_log` 데코레이터 복구
팀원분이 업데이트한 함수 내용(특히 복잡해진 `tool_book_appointment` 등)은 100% 그대로 유지하되, 함수 선언부 위에만 데코레이터를 다시 씌워줍니다.

```diff
+ @audit_log("list_documents")
  def tool_list_documents() -> str:
      ...

+ @audit_log("rag")
  def tool_rag(question: str) -> str:
      ...

+ @audit_log("direct_answer")
  def tool_direct_answer(question: str) -> str:
      ...

+ @audit_log("book_appointment")
  def tool_book_appointment(question: str, patient_id: Optional[int]) -> str:
      # 팀원분이 작성하신 자연어 파싱 및 휴진일 체크 로직 그대로 유지
      ...

+ @audit_log("check_appointments")
  def tool_check_appointments(patient_id: Optional[int]) -> str:
      ...

+ @audit_log("check_medical_records")
  def tool_check_medical_records(patient_id: Optional[int]) -> str:
      ...
```

#### 3. 변경 불가 영역 유지
* `parse_datetime_kr`, `find_department`, `is_within_business_hours` 등 팀원분이 새로 작성한 파싱 함수 및 휴무일 로직은 전혀 수정하지 않고 그대로 둡니다.
* 업데이트된 `choose_action` (예약 단어 매칭 조건 강화) 로직 역시 팀원분의 버전으로 유지합니다.
